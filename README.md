# ChatLens by EVERGROW GLOBAL SOLUTIONS PRIVATE LIMITED

ChatLens is one browser-based WhatsApp conversation analysis app. Beta V48 supports TXT and compatible ZIP exports, multiple exports of the same conversation in one analysis, local statistics and historical activity, language and context cues, individual views, and printable or shareable reports.

Chat contents are processed locally in the browser. Account sign-in and analysis limits use Supabase. Exact duplicate messages are removed only when overlapping exports are combined; repeated messages inside an individual export remain counted. When combining exports, use files from the same conversation with the same date format and displayed clock.

This beta uses statistical and keyword rules. It does not claim AI understanding, determine intent or feelings, or provide relationship, medical, psychological, or legal advice. Paid plans and Razorpay checkout are not enabled in the current app.

Live demo: https://vespalabs.github.io/ChatLens/
